# iPhone 歷史價格查詢頁

## 入口與建置

首頁的「歷代官方價格」連至 `prices.html`，返回連結仍導向公開交易觀測網站。這是獨立的參考頁，不變更行情統計、爬蟲、收藏或 `data/` CSV。

`site/build_site.py` 將 `prices.html`、`prices.js`、`prices.css` 與 `official-prices.json` 複製到網站根目錄，沿用原有 Pages 建置；不需要 Drive 登入、公開試算表權限、新套件或執行時 API。

## 2026-10-02 匯入與發布邊界

來源為同日「iPhone歷代官方價格查核表_2026-10-02_待查核」主檔的台灣價格明細、後續容量與調價、初代美國價格。私人 Drive 入口、帳號、留言板與完整 Excel 不提交至公開 repo。

- 原主表 164 筆中，12 筆 E 級（機型／官方索引本身仍待核）整筆不公開，公開主表保留 152 筆。
- 加入後續容量／調價 15 筆及初代美國價 4 筆，共 171 筆、52 個機型。
- 證據分級沿用底稿：A 57（其中台灣上市價 52、後增容量 1、美國 4）；B 6；C 105；F 1；N 2。此次不是全面重新核價或將待查升級。
- 只有 A（Apple 原文）及 B（電信官方）有公開金額。C（轉載待原件）、F（時點待複核）、N（台灣不適用）一律為 `null`，備註不攜帶待查價格。
- 不匯入官網快照，避免把查詢當日頁面價格當成歷史上市價。未核實的機型名稱／上市日期也不公開。

預設為台灣上市區塊與 A 級；「全部查核狀態」可看待查行，但不會顯示隱藏價格。B 級獨立標示定價主體及價格類型：其中包含電信預付卡方案，也有電信公告空機價，均不冒充 Apple 直售定價。美國價格不轉換台幣。不計算折價率、保值率或混合幣別統計。

## 維護方式

`official-prices.json` 是版本化、去除未核實金額的公開快照；不是 Drive 即時同步。先在底稿補足相符的機型、容量、市場、幣別、時點及官方原件，再經獨立 PR 更新快照。不能僅因網址位於 Apple 網域、看到搜尋摘要或今天商店有價，就將歷史上市價升為 A。

JSON 的 `columns` 明列每筆陣列欄位，`sources` 以 ID 去重保留原始網址。`section` 決定市場及幣別：`tw-launch`、`tw-later` 為 TWD，`us` 為 USD。`year` 是機型初發年，不是每筆價格的生效年；`effective_date` 允許底稿原有的月份／季度或空白，不自行補日期。`withheld_records` 是未刊出 E 級的數量。

公開數值必須是正整數；非 A/B 的金額必須為 `null`。新增其他官方定價主體時同步更新來源主體檢查。未核實原始數字不要藏在備註、HTML、JavaScript 或靜態 JSON 裡。所有畫面文字透過 `textContent` 建立；外連只接受無登入資訊的 HTTPS。

可用查詢參數分享同一組條件：`section`、`evidence`、`year`、`storage`、`q`、`sort`。不存在的條件不會讓頁面執行注入內容；無結果、載入失敗、重試、禁用 JavaScript 都有提示。

## 驗證

```sh
python -m unittest
node --test tests/*.test.cjs
python site/build_site.py --out _site
python -m http.server -d _site 8000
```

覆核 `prices.html` 在手機、桌面及深色模式的篩選、橫向表格、來源、待查／不適用、三種價格區塊與失敗重試。所有更新只走 branch + PR，人工覆核後再決定合併；不要直接推 main 或觸發部署。
